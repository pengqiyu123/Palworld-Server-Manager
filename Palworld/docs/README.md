# 项目文档

本目录是项目唯一的文档入口。面向当前开发和维护的材料按主题分类；历史方案、交接记录和早期界面探索保留在 `archive/`，仅供追溯，不应作为当前实现依据。

## 当前文档

- `research/`：Palworld 存档格式、竞品能力、角色/公会关联与三档配置调研。
- `product/`：产品需求、迁移任务流与用户体验研究。
- `architecture/`：桌面应用架构与当前存档迁移设计。
- `release/`：v1.0.0 的真实迁移验收、实现记录和发布证据。

## 历史归档

- `archive/handoffs/`：阶段性交接、勘误和认知校正记录。
- `archive/pre-release-design/`：发布前已被当前方案替代的设计稿和图表。
- `archive/research-validation/`：一次性验证与数据迁移实验记录。
- `archive/release-prep/`：首次启动、补丁和版本统一检查记录。
- `archive/reviews/`：已完成的 UX/架构评审。
- `archive/ui-research/`：早期窗口与标题栏研究。

运行与发布说明见仓库根目录的 `README.md`、`CHANGELOG.md` 和 `THIRD_PARTY_NOTICES.md`。
