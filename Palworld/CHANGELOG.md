# Changelog

## 1.0.1 - 2026-07-28

- 修复已有 `PalWorldSettings.ini` 被误报为空配置的问题。
- 将服务器初始化与启动状态分离，离线按钮不再一直显示“启动中”。
- 用可刷新、复制、导出和清空的“系统日志”替代故障排查页。
- 自动记录真实 Tauri 操作错误并在落盘前脱敏，便于远程反馈。
- 修复便携版构建在重启后找不到 Node 的 PATH 问题，并清理仓库布局。

## 1.0.0 - 2026-07-27

首个正式版本。

- 完成 PalServer 外部/内部进程同步、REST 实时状态、玩家管理和安全停服。
- 完成 Radmin VPN 与游戏启动引导、三档玩法配置和配置备份。
- 完成本地/服务器世界发现、完整备份、回滚点和结构化详情。
- 完成世界迁移、完整角色转移、朋友角色导入和可选公会恢复工作流。
- 完成玩家/公会修改器及停服、原子写入、回读验证和故障回滚保护。
- 修复 REST 保存世界缺少 `Content-Length: 0` 导致 HTTP 411 的问题。
- 将公开版本、安装包和界面统一为 `1.0.0`。
